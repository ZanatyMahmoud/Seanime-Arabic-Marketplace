# Plugins

Plugins are referenced from their original manifests rather than copied. The checked-in fallback includes Account Switcher, UI Translation, AnimeThemes Player, Watch Order, Watch Next, Dub Schedule and several official/community utilities.

AIOStreams is not hard-coded to a guessed manifest URL: its current Seanime integration generates an installation manifest from an AIOStreams instance/configuration. Add that generated manifest through AIOStreams' **Save & Install → Other Apps → Seanime** workflow unless a stable universal marketplace manifest becomes available.
